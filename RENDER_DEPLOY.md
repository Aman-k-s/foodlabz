## Render Deploy (Django API)

This repo includes:
- `render.yaml` (Blueprint)
- `Dockerfile` (installs Tesseract + Poppler for OCR)

### 1) Push to GitHub
Push latest code including `render.yaml` and `Dockerfile`.

### 2) Create service on Render
- Render Dashboard -> New -> Blueprint
- Select your repo
- Render reads `render.yaml` and creates `foodlabz-django-api`

### 3) Set required environment variables in Render
- `DJANGO_SECRET_KEY` (auto-generated by Blueprint)
- `DJANGO_DEBUG=false`
- `DJANGO_ALLOWED_HOSTS=.onrender.com`
- `DATABASE_URL` (if using Render Postgres)
- `CORS_ALLOWED_ORIGINS` = your Vercel frontend domain, e.g. `https://your-app.vercel.app`

### 4) Deploy
Render builds Docker image and runs:
- `python manage.py migrate`
- `gunicorn config.wsgi:application --bind 0.0.0.0:$PORT`

### 5) Connect frontend
In Vercel env vars:
- `VITE_DJANGO_API_BASE=https://<your-render-domain>.onrender.com`
